# Manual de uso do Vôlei+

Este guia explica como acessar as telas do Vôlei+ e executar as tarefas principais. A interface atual está em desenvolvimento; o uso completo depende da API estar disponível.

## 1. Acessar o sistema

1. Abra o endereço informado pela equipe do projeto.
2. Na tela **Entrar**, informe o e-mail e a senha cadastrados e selecione **Entrar**.
3. Para uma conta nova, selecione **Cadastrar-se**, informe nome, e-mail e senha e confirme a senha.
4. Se aparecer uma mensagem de erro, confira os campos e tente novamente. O botão mostra quando a solicitação está sendo enviada.

## 2. Criar uma equipe

1. No menu, abra **Equipes**.
2. Selecione **Nova equipe**.
3. Informe o nome e a categoria e salve.
4. Abra o cartão da equipe para acessar atletas e treinos.
5. Para editar ou inativar, use o menu de ações do cartão e confirme a operação quando solicitado.

## 3. Cadastrar atletas

1. Abra a equipe e selecione **Atletas**.
2. Selecione **Novo atleta**.
3. Preencha nome, data de nascimento e posição. Número da camisa é opcional.
4. Salve. Para corrigir os dados depois, abra o atleta e selecione **Editar**.
5. Para preservar o histórico sem incluir o atleta em novas chamadas, use **Inativar**.

## 4. Registrar um treino

1. Dentro da equipe, abra **Treinos** e selecione **Novo treino**.
2. Informe data, tema e observações.
3. Salve. A lista mostra os treinos da equipe em ordem cronológica.
4. Para corrigir ou excluir um treino, use o menu de ações correspondente.

## 5. Fazer a chamada

1. Na lista de treinos, abra **Chamada** no treino desejado.
2. Marque cada atleta como presente ou ausente. Também é possível usar **Marcar todos presentes** e ajustar casos individuais.
3. Confira a contagem de presentes e ausentes e selecione **Salvar chamada**.
4. Para corrigir depois, reabra a chamada e salve as marcações atualizadas.

## 6. Registrar uma avaliação

1. Abra o perfil do atleta e selecione **Nova avaliação**.
2. Dê uma nota de 1 a 5 para passe, saque, ataque, bloqueio e defesa.
3. Inclua observações se necessário e salve.
4. A avaliação salva aparece no histórico do atleta.

## 7. Consultar o perfil e a evolução

1. Abra **Atletas** na equipe e selecione o atleta.
2. O perfil reúne dados, presença e avaliações disponíveis.
3. Abra **Evolução** para ver as notas por fundamento ao longo do tempo e o percentual de presença.
4. Com menos de duas avaliações, o sistema informa que ainda não há dados suficientes para mostrar a tendência.

## Privacidade

Use apenas dados autorizados pelo treinador e pela instituição. Para atletas menores de 18 anos, confirme a autorização dos responsáveis antes de inserir dados. Não use nomes ou dados reais em demonstrações públicas.

## Capturas de tela e validação

As capturas da interface e a validação deste guia com alguém que não participou do projeto serão anexadas após a sessão de teste com o treinador. Até essa validação, este manual é uma versão de trabalho.
